# 🐾 Puppy House - Criadero Certificado & Nutrición Premium

**Puppy House** es una plataforma de alto rendimiento diseñada para una experiencia de usuario fluida y "viva". Este sitio no solo es una vitrina, sino un ecosistema digital completo para amantes de las mascotas.

## 🔍 Análisis de Secciones

El sitio está diseñado como una *Landing Page* de alta conversión con bloques estratégicos:
1. **Navigación Glassmorphism:** Menú persistente con efectos de desenfoque.
2. **Hero Impactante:** Imagen cinematográfica con zoom lento y CTAs claras.
3. **Barra de Confianza:** Información sobre la certificación del Kennel Club Chile y envíos nacionales.
4. **Catálogo de Razas:** Filtrado dinámico (Razas pequeñas/grandes) con animaciones de *Framer Motion*.
5. **Nutrición Belcando:** Presenta a Puppy House como distribuidor oficial de la nutrición alemana premium.
6. **Logística de Envío:** Detalle de transporte aéreo y terrestre para el bienestar del cachorro.

## 🛠️ Especificaciones Técnicas

- **Core:** Next.js 15+ (App Router) para carga ultra-rápida.
- **Interacciones:** Animaciones fluidas mediante **Framer Motion**.
- **Estilos:** Tailwind CSS v4 para un diseño utilitario y moderno.
- **Optimización:** WebP dinámico, lazy loading y sitemap dinámico para SEO.
