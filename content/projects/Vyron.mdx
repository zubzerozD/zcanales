## Sobre el Proyecto

VYRON es una boutique urbana premium de streetwear y sneakers de edición limitada, ubicada en Hualpén, Chile. El sitio es una PWA completa con SEO profesional y estructura de e-commerce.

## Características

1. **PWA Completa**
   - Manifest para instalación en móvil
   - Robots.txt para crawlers
   - Sitemap XML con prioridades
   - Viewport optimizado

2. **SEO Profesional**
   - Metadata completa (OpenGraph, Twitter, formatDetection)
   - Authors y creator/publisher definidos
   - Constantes tipadas para consistencia

3. **Catálogo**
   - Calzado: Nike, Jordan, Adidas, New Balance, Yeezy, Salomon
   - Vestuario: Fear of God, Essentials, Nike Tech, Supreme
   - Lujo: Louis Vuitton, Dior, Gucci, Balenciaga, Prada

4. **Showroom Privado**
   - Atención con cita programada
   - Coordinación por WhatsApp
   - Experiencia exclusiva

## Stack Técnico

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- PWA (manifest, robots, sitemap)
