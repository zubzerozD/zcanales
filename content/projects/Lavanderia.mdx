## Arquitectura del Sistema

Una solución completa desarrollada con tecnologías web modernas para digitalizar los procesos operativos de una lavandería.

### Stack Tecnológico
- **Frontend:** React / Next.js para una interfaz de usuario reactiva y amigable.
- **Backend:** Node.js con Express para la API RESTful.
- **Base de Datos:** Integración con modelos relacionales para el manejo de datos críticos.

### Módulos Principales
1. **Control de Maquinaria:** Monitoreo de estado y mantenimiento.
2. **Gestión de Suministros:** Inventario en tiempo real de insumos.
3. **Finanzas:** Registro de pagos (`paymentrecord`) y libros contables (`ledger`).
4. **Usuarios:** Sistema de roles y autenticación segura con JWT.
