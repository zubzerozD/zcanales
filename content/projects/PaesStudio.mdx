## Sobre el Proyecto

PAES Studio es una plataforma web completa para practicar la Prueba de Acceso a la Educación Superior (PAES) en Chile. No es solo un formulario — tiene UX pulida con funciones de productividad para estudiantes.

## Datos

- **40 exámenes** de años anteriores (2025-2027)
- **2,401 preguntas** totales
- **8 materias**: Biología, Física, Química, Técnico Profesional, Competencia Lectora, M1, M2, Historia

## Funcionalidades

1. **Keyboard Shortcuts**
   - Atajos de teclado para navegar entre preguntas
   - Popover de hints para descubrir los atajos

2. **Question Navigator Grid**
   - Grid con colores: actual, respondida, correcta, incorrecta
   - Desktop: sidebar al lado de la pregunta
   - Mobile: bottom sheet overlay

3. **Flag/Unflag Questions**
   - Marcar preguntas para revisión
   - Sistema de banderas para organizar el estudio

4. **Temporizador Real**
   - Cronómetro por examen (120-150 minutos según materia)
   - Simula condiciones reales de la prueba

## Stack Técnico

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Componentes modulares (QuestionNav, FlagButton, etc.)
