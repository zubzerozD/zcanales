# RobStudioFit - Elite Personalized Training & Clinical Rehab

**RobStudioFit** es un ecosistema digital diseñado para un centro boutique que se aleja del concepto de gimnasio tradicional masivo. Su propuesta de valor se centra en la excelencia técnica y la exclusividad.

## 🧐 ¿De qué trata el proyecto?

El proyecto refleja un modelo de negocio enfocado en:
- **Entrenamiento Biomecánico:** Sesiones guiadas basadas en la estructura física individual.
- **Kinesiología Deportiva:** Supervisión clínica para rehabilitación y prevención de lesiones.
- **Exclusividad:** Sistema de aforo controlado para garantizar calidad técnica.

## 📁 Estructura de la Aplicación

La plataforma utiliza una estética **Dark Premium** con acentos en **Fuchsia Custom**, organizada en secciones estratégicas:

1. **Home:** Navegación visualmente rica con Bento Grids y videos de fondo.
2. **Servicios:** Detalle de entrenamientos guiados y reintegro deportivo.
3. **Rehabilitación:** Programas clínicos de supervisión kinesiología.
4. **Evaluación:** Sistema de captación para análisis biomecánico sin costo.
5. **Horarios:** Gestión de tiempo optimizada sin aglomeraciones.

## 🛠️ Stack Tecnológico

- **Frontend:** Next.js 16 (App Router) y React 19.
- **Lenguaje:** TypeScript para un desarrollo robusto.
- **Estilos:** Tailwind CSS v4 con configuraciones personalizadas y Glassmorphism.
- **Optimización:** Carga diferida mediante `next/image` y videos optimizados.
