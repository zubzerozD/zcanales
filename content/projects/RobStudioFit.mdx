## Sobre el Proyecto

**ROB STUDIO FIT** es una plataforma dedicada al entrenamiento personalizado de alto rendimiento. El enfoque principal es la biomecánica individual, ofreciendo un ambiente exclusivo libre de distracciones para maximizar los resultados de cada sesión.

### Características Principales
- **Entrenamiento Personalizado:** Rutinas adaptadas a la biomecánica del usuario.
- **Ambiente Exclusivo:** Sin aglomeraciones, enfocado 100% en el cliente.
- **Gestión de Sesiones:** Sistema optimizado para el seguimiento de resultados.

### Tecnologías Utilizadas
- **Frontend:** React 19 / Next.js 16
- **Estilos:** Tailwind CSS v4
- **Optimización de Imagen:** Conversión HEIC integrada.
- **Despliegue:** Vercel
