## 🧘 Visión del Proyecto

Este proyecto consiste en el desarrollo de una identidad digital completa para una consulta de hipnoterapia. El desafío principal fue equilibrar una **estética terapéutica y minimalista** con una **ingeniería robusta**.

A diferencia de las webs médicas tradicionales, este sitio fue concebido con una filosofía *Mobile-First* agresiva, comportándose como una aplicación nativa en dispositivos móviles para facilitar el agendamiento de horas en momentos de necesidad del usuario.

## 🛠️ Stack Tecnológico de Vanguardia

Se utilizó el ecosistema más reciente de React para garantizar longevidad y rendimiento:

- **Core:** **Next.js 16 (App Router)** y **React 19** para un renderizado híbrido y veloz.
- **Estilos:** **Tailwind CSS v4**, aprovechando el nuevo motor de compilación para un CSS ultraligero.
- **Contenido:** **Velite** para la gestión de contenidos (servicios y blog) con seguridad de tipos.
- **Backend:** API Routes integradas para el manejo de formularios y lógica de servidor.

## ✨ Características Clave

### 1. Diseño Sensorial y "Glassmorphism"
La interfaz se aleja de lo corporativo para abrazar lo humano. Se implementó una paleta de colores psicológicamente estudiada (tonos violetas, esmeralda y arena) junto con efectos de vidrio esmerilado (`backdrop-blur`) en la navegación, creando una atmósfera de calma y profesionalismo.

### 2. Navegación Híbrida Inteligente
Para mejorar la experiencia de usuario (UX), se desarrolló un sistema de navegación dual:
- **En Escritorio:** Una barra superior limpia y expansiva.
- **En Móvil:** Una interfaz adaptativa que prioriza la accesibilidad táctil, similar a una app nativa de bienestar.

### 3. Sistema de Contacto Seguro
Se implementó un backend funcional dentro de Next.js. El formulario de contacto no depende de servicios de terceros; utiliza `Nodemailer` en una ruta de API protegida (`/api/contact`) para gestionar las solicitudes de los pacientes de manera privada y directa.

### 4. Optimización SEO para Salud Local
Gracias al **Server-Side Rendering (SSR)** de Next.js, el sitio está altamente optimizado para búsquedas locales ("hipnoterapia cerca de mí"), asegurando que los tiempos de carga (LCP) sean casi instantáneos, un factor crucial para retener a usuarios con ansiedad o urgencia.
