# BioGPS Chile - Bitek Solutions

**Bitek Solutions** es una plataforma moderna diseñada para presentar servicios de consultoría tecnológica, desarrollo de software y el ERP operativo **Biot**. Enfocado en la optimización de procesos industriales y de manufactura, el sitio ofrece una experiencia de usuario premium con animaciones fluidas y un diseño orientado a la conversión.

## ✨ Características Principales

- **Diseño Ultra-Premium:** Interfaz moderna con modo oscuro, degradados dinámicos y estética de "glassmorphism".
- **Animaciones Avanzadas:** Integración profunda con Framer Motion para transiciones suaves y micro-interacciones.
- **Optimización SEO:** Estructura semántica de HTML5 y metadatos optimizados para buscadores.
- **Totalmente Responsivo:** Experiencia optimizada para móviles, tablets y desktops.
- **Integraciones:** Conexión directa con WhatsApp para consultas rápidas y secciones de showcase de video.
- **Rendimiento:** Basado en Next.js con soporte para React Server Components y las últimas optimizaciones de React 19.

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 15+ (App Router)
- **Librería UI:** React 19
- **Estilos:** Tailwind CSS 4
- **Animaciones:** Framer Motion
- **Lenguaje:** TypeScript
- **Fuentes:** Google Fonts (Geist, Outfit, Inter)

## 🏗️ Estructura del Proyecto

- **Rutas:** Directorio `app/` utilizando Next.js App Router.
- **Componentes:** Arquitectura modular y reutilizable de la interfaz.
- **Estilos:** Configuraciones de Tailwind y CSS global optimizado.
- **Activos:** Showcase de video y recursos visuales de alta calidad.
